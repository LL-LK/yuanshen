导数与应用

导数是变化的瞬间，积分是累积的永恒。如枫丹流水的绵延不绝，微积分以极限思想贯穿变化与累积，是高中数学的最高阶工具。本章覆盖极限、导数、导数应用、定积分。

本章知识体系

壹

极限与连续

单元一

  • 数列极限 lim(n→∞) an=A：n 无限增大时 an 趋近于常数 A。
  • 函数极限 lim(x→x₀) f(x)：x 趋近 x₀ 时 f(x) 的变化趋势。
  • 函数极限 lim(x→∞) f(x)：|x| 无限增大时 f(x) 的变化趋势。
  • 左极限 lim(x→x₀⁻) f(x) 与右极限 lim(x→x₀⁺) f(x)。
  • 极限存在的充要条件：左右极限均存在且相等。
  • 极限四则运算法则（和、差、积、商，分母极限非零）。
  • 两个重要极限：lim(x→0) sinx/x=1，lim(x→∞) (1+1/x)x=e。
  • 无穷小量与无穷大量及其互倒关系；常见等价无穷小 x~sinx~ln(1+x)~ex-1（x→0）。
  • 函数连续性定义：lim(x→x₀) f(x)=f(x₀)。
  • 闭区间上连续函数的性质：最值定理、零点存在定理。

核心公式

lim(x→0) sinx/x = 1　·　lim(x→∞) (1+1/x)x = e　·　lim(x→x₀) f(x) = f(x₀)

方法要点与易错警示

求极限先判类型，未定式需约分、有理化或等价无穷小替换化简；分段函数分界处务必分别求左右极限，二者相等极限才存在；等价无穷小替换只能用于乘除因子，不可用于加减项。

贰

导数的概念与运算

单元二

  • 导数定义 f'(x₀)=lim(Δx→0) [f(x₀+Δx)-f(x₀)]/Δx。
  • 左导数 f'₋(x₀) 与右导数 f'₊(x₀)。
  • 可导的充要条件：左导数与右导数均存在且相等。
  • 可导与连续的关系：可导必连续，连续不一定可导（如 y=|x| 在 x=0 处）。
  • 导数的几何意义：曲线在切点处切线的斜率。
  • 导数的物理意义：瞬时变化率（瞬时速度、边际量等）。
  • 基本公式：c'=0，(xⁿ)'=nxⁿ⁻¹。
  • 指数对数导数：(eˣ)'=eˣ，(aˣ)'=aˣlna，(lnx)'=1/x，(logₐx)'=1/(xlna)。
  • 三角函数导数：(sinx)'=cosx，(cosx)'=-sinx。
  • 导数四则运算法则：(u±v)'=u'±v'，(uv)'=u'v+uv'，(u/v)'=(u'v-uv')/v²。
  • 复合函数链式法则 [f(g(x))]'=f'(g(x))·g'(x)；隐函数求导初步。

核心公式

(uv)' = u'v + uv'　·　(u/v)' = (u'v - uv')/v²　·　[f(g(x))]' = f'(g(x))·g'(x)

方法要点与易错警示

求导前先化简（展开、因式分解），优先用四则法则再处理复合部分；复合函数“由外向内”逐层求导，每层不漏乘内层导数；分段函数分界点用定义求左右导数判断可导性，不可直接套公式。

叁

导数的应用（函数性质研究）

单元三

  • 用导数判断单调性：f'(x)>0 单调递增，f'(x)<0 单调递减。
  • 求单调区间的步骤：定域 → 求 f'(x) → 解 f'(x)≥0 或 ≤0 → 写区间。
  • 极值点必要条件：f'(x₀)=0 或导数不存在。
  • 极值的充分条件：x₀ 两侧 f'(x) 变号（左正右负为极大，左负右正为极小）。
  • 极值与最值的区别：极值是局部概念，最值是整体概念。
  • 闭区间 [a,b] 上最值：比较所有极值与端点函数值。
  • 优化问题：实际应用中建立目标函数，求最值后作答。
  • 切线方程：y-y₀=f'(x₀)(x-x₀)。
  • 公切线问题：两函数切线重合，联立斜率与切点方程组求解。
  • 函数图象分析：综合单调性、极值、特殊点绘制大致图象。

核心公式

f'(x) > 0 → 增　·　f'(x) < 0 → 减　·　切线：y - y₀ = f'(x₀)(x - x₀)

方法要点与易错警示

f'(x₀)=0 只是极值必要条件，必须验“变号”才能定极值（如 x³ 在 0 处非极值）；求最值勿漏端点，开区间或无穷区间需结合单调性与极限判断；含参数单调性讨论要按 f'(x)=0 的根的大小分类，并注意定义域限制。

肆

导数的综合应用（不等式与零点）

单元四

  • 构造函数法证不等式：将不等式转化为 F(x)≥0，用单调性证明。
  • 导数与方程根：f(x)=0 的零点个数由单调性、极值与端点符号判断。
  • 零点所在范围：用零点存在定理（端点函数值异号）定位。
  • 分离参数法：将参数 a 分离为 a≥g(x) 或 a≤g(x)，求 g(x) 最值。
  • 分类讨论法：按参数取值对单调性、极值分布分情况讨论。
  • 双变量与极值点偏移：利用极值点关系构造对称函数处理。
  • 含 eˣ 的放缩：eˣ≥x+1（x∈R），等号当 x=0 成立。
  • 含 lnx 的放缩：lnx≤x-1（x>0），等号当 x=1 成立。
  • 洛必达法则初步：对 0/0 或 ∞/∞ 型未定式，lim f(x)/g(x)=lim f'(x)/g'(x)。

核心公式

eˣ ≥ x + 1　·　lnx ≤ x - 1　·　lim f(x)/g(x) = lim f'(x)/g'(x)（0/0 或 ∞/∞ 型）

方法要点与易错警示

证不等式优先“构造函数 + 单调性”，遇差值考虑构造 F(x)=左-右；零点个数需结合单调性画草图，警惕零点恰为极值点的特殊情形；分离参数后若 g(x) 最值以极限形式趋近，临界值常需单独验证。

伍

定积分与微积分基本定理

单元五

  • 定积分概念：分割-近似-求和-取极限，∫[a,b] f(x)dx=lim Σf(ξᵢ)Δx。
  • 定积分的几何意义：x 轴上方曲边梯形面积（下方取负值）。
  • 定积分的线性性：∫[a,b] [kf(x)+g(x)]dx=k∫f(x)dx+∫g(x)dx。
  • 区间可加性：∫[a,b] f(x)dx=∫[a,c] f(x)dx+∫[c,b] f(x)dx。
  • 比较性（保号性）：f(x)≥g(x) 则 ∫[a,b] f(x)dx≥∫[a,b] g(x)dx。
  • 微积分基本定理（牛顿-莱布尼茨公式）：∫[a,b] f(x)dx=F(b)-F(a)，F'(x)=f(x)。
  • 基本积分公式：∫xⁿdx=xⁿ⁺¹/(n+1)+C，∫eˣdx=eˣ+C，∫1/x dx=ln|x|+C。
  • 定积分求曲边图形面积：S=∫[a,b] |f(x)-g(x)|dx。
  • 旋转体体积初步：V=π∫[a,b] [f(x)]²dx（绕 x 轴旋转）。
  • 变限积分求导初步：d/dx ∫[a,x] f(t)dt=f(x)。

核心公式

∫[a,b] f(x)dx = F(b) - F(a)，其中 F'(x) = f(x)　·　∫xndx = xn+1/(n+1) + C

方法要点与易错警示

用牛顿-莱布尼茨公式须先确认 f(x) 在 [a,b] 连续，并正确求出原函数；求面积先定上下函数，按交点分段，对各段积“上-下”的绝对值；被积函数含绝对值或分段时，按零点或分界点拆区间分别积分。
