数系扩充与复数

单元一

  • 复数的概念：z = a + bi（a, b ∈ R，i² = −1），a 为实部、b 为虚部
  • 复数相等的充要条件：实部与虚部分别相等，即 a = c 且 b = d
  • 复数的分类：b = 0 为实数，b ≠ 0 为虚数，a = 0 且 b ≠ 0 为纯虚数
  • 复数的几何意义：复数与复平面上的点 Z(a, b) 及向量 OZ 一一对应
  • 复数的模：|z| = √(a² + b²)，几何上为对应向量的长度
  • 共轭复数：z = a + bi 与 z̄ = a − bi，实部相等、虚部互为相反数
  • 复数的加减法：(a + bi) ± (c + di) = (a ± c) + (b ± d)i
  • 复数的乘除法：(a + bi)(c + di) = (ac − bd) + (ad + bc)i，除法分子分母同乘分母共轭复数
  • 复数加减的几何意义：遵循向量加减的平行四边形法则与三角形法则
  • 复数的三角形式：z = r(cosθ + isinθ)，其中 r = |z|，θ 为辐角
  • 棣莫弗公式：[r(cosθ + isinθ)]ⁿ = rⁿ(cos nθ + i sin nθ)
  • 实系数一元二次方程：Δ < 0 时虚根成对出现（互为共轭复数），韦达定理仍成立

核心公式

|z| = √(a² + b²)
z̄ = a − bi
z = r(cosθ + isinθ)
[r(cosθ + isinθ)]ⁿ = rⁿ(cos nθ + i sin nθ)

方法要点与易错警示

· 复数相等的充要条件是实部、虚部分别相等，常用于由复数相等求参数值。
· 纯虚数须同时满足 a = 0 且 b ≠ 0，判定时切忌遗漏 b ≠ 0。
· 化三角形式时须保证 r ≥ 0 且辐角 θ 与点 (a, b) 所在象限一致，否则不能直接套用棣莫弗公式。

贰

推理与证明

单元二

  • 合情推理之归纳推理：由特殊到一般，从个别事实概括出一般结论
  • 合情推理之类比推理：由特殊到特殊，依据两类对象的相似性迁移性质
  • 演绎推理：由一般到特殊的必然性推理，结论可靠
  • 三段论的结构：大前提（一般原理）、小前提（特殊情形）、结论
  • 直接证明之综合法：由已知条件出发，顺推导出结论（由因导果）
  • 直接证明之分析法：从结论出发，逆向寻找使之成立的充分条件（执果索因）
  • 间接证明之反证法：假设结论不成立，导出矛盾从而否定假设
  • 反证法的适用场景：结论含“至多”“至少”“唯一”或为否定性命题时
  • 反证法步骤：否定结论 → 合理推理论证 → 导出矛盾（与已知、公理或假设矛盾）
  • 数学归纳法步骤①（归纳奠基）：验证 n = n₀ 时命题成立
  • 数学归纳法步骤②（归纳递推）：假设 n = k 成立，证明 n = k+1 也成立
  • 数学归纳法的应用：证明等式、不等式、整除性问题与数列通项公式

核心公式

数学归纳法：
① 归纳奠基：验证 n = n₀ 时命题成立
② 归纳递推：假设 n = k 成立 ⇒ 证明 n = k+1 成立

方法要点与易错警示

· 归纳推理与类比推理的结论不一定正确，须经严格证明方可确信。
· 综合法与分析法常结合使用，分析法探路、综合法表述，注意每步须为可逆的充要推演。
· 数学归纳法两步缺一不可，递推证明时必须用到归纳假设，且由 k 到 k+1 的变形要恰好衔接假设。

极坐标与参数方程

单元三

  • 极坐标系的概念：取极点 O、极轴 Ox，由极径 ρ 与极角 θ 确定点 P(ρ, θ)
  • 极坐标与直角坐标互化：x = ρcosθ，y = ρsinθ
  • 反向互化：ρ² = x² + y²，tanθ = y/x（θ 由点 (x, y) 所在象限确定）
  • 圆的极坐标方程：极点为圆心时 ρ = r；过极点且圆心在 (r, 0) 时 ρ = 2r cosθ
  • 直线的极坐标方程：过极点时 θ = α；一般直线 ρcos(θ − α) = a
  • 心形线等典型曲线：ρ = a(1 + cosθ) 等玫瑰线、心形线方程
  • 参数方程的概念：x = f(t)，y = g(t)，t 为参数，刻画动点轨迹
  • 直线的参数方程：过点 P₀(x₀, y₀) 倾斜角 α，x = x₀ + t cosα，y = y₀ + t sinα
  • 圆的参数方程：圆心 (a, b) 半径 r，x = a + r cosθ，y = b + r sinθ
  • 椭圆的参数方程：x²/a² + y²/b² = 1 对应 x = a cosθ，y = b sinθ
  • 参数方程与普通方程互化：消去参数（代入法、平方相加法），注意等价性
  • 参数方程的应用：求动点轨迹方程、求最值与取值范围问题

核心公式

x = ρcosθ，y = ρsinθ
ρ² = x² + y²，tanθ = y/x
圆参数方程：x = a + r cosθ，y = b + r sinθ
椭圆参数方程：x = a cosθ，y = b sinθ

方法要点与易错警示

· 极坐标与直角坐标互化须先约定极点与原点重合、极轴与 x 轴正半轴重合。
· 由 tanθ = y/x 反求 θ 时必须结合点 (x, y) 所在象限确定终边，不能只取主值。
· 化参数方程为普通方程后须注明参数取值范围对应的曲线范围，避免范围扩大或缩小。

平面向量

单元四

  • 向量的概念：既有大小又有方向的量，常用有向线段表示
  • 零向量与单位向量：零向量 |0| = 0 且方向任意，单位向量 |e| = 1
  • 向量的加减法：三角形法则（首尾相接）与平行四边形法则（共起点）
  • 向量的数乘：λa 的模为 |λ||a|，λ > 0 同向、λ < 0 反向，几何意义为伸缩
  • 向量共线定理：b ≠ 0 时，a ∥ b ⟺ 存在唯一实数 λ 使 a = λb
  • 平面向量基本定理：e₁, e₂ 不共线，任一向量 a = λ₁e₁ + λ₂e₂ 唯一分解
  • 向量的坐标表示：a = (x, y)，加减与数乘对应坐标分别运算
  • 数量积（点积）：a·b = |a||b|cosθ = x₁x₂ + y₁y₂
  • 向量平行的坐标条件：a ∥ b ⟺ x₁y₂ − x₂y₁ = 0
  • 向量垂直的坐标条件：a ⊥ b ⟺ a·b = 0 ⟺ x₁x₂ + y₁y₂ = 0
  • 向量夹角公式：cosθ = (a·b) / (|a||b|)，θ ∈ [0, π]
  • 定比分点公式：点 P 分 AB 满足 AP = λPB，则 OP = (OA + λOB) / (1 + λ)

核心公式

a·b = |a||b|cosθ = x₁x₂ + y₁y₂
a ∥ b ⟺ x₁y₂ − x₂y₁ = 0
a ⊥ b ⟺ x₁x₂ + y₁y₂ = 0
cosθ = (a·b) / (|a||b|)

方法要点与易错警示

· 零向量方向任意，与任何向量都平行，讨论共线时勿忘 b ≠ 0 的前提。
· 数量积运算不满足结合律，不能写成 (a·b)·c = a·(b·c)。
· 用夹角公式求 θ 时须先由数量积符号判断 θ 为锐角还是钝角，再确定 cosθ 的正负，避免象限误判。
