几何与图形

璃月 · 岩元素

几何是空间的语言，图形是逻辑的具象。如璃月港岩山的稳固，立体几何与解析几何构筑了空间思维与坐标方法的双重基石。本章覆盖立体几何、空间向量、解析几何、圆锥曲线。

知识单元

壹

立体几何

单元一

  • 空间点、直线、平面的位置关系：线在面内、线面相交、线面平行
  • 平面基本性质四公理：公理1-3及推论确定平面，公理4为平行传递性
  • 等角定理：两边分别平行且方向相同则两角相等
  • 异面直线所成角与异面直线距离
  • 线线、线面、面面平行的判定定理
  • 线线、线面、面面平行的性质定理
  • 线线、线面、面面垂直的判定定理
  • 线线、线面、面面垂直的性质定理
  • 线线角、线面角的定义与求法
  • 二面角的定义、二面角的平面角及求法
  • 空间距离：点面距、线面距、面面距的转化求解
  • 多面体与旋转体的表面积、体积及外接球、内切球

核心公式

柱体体积：V = Sh
锥体体积：V = Sh/3
台体体积：V = (S₁+√(S₁S₂)+S₂)h/3
球体积：V = 4πR³/3
球面面积：S = 4πR²
圆柱侧面积：S = 2πrl
圆锥侧面积：S = πrl

方法要点与易错警示

· 证明平行与垂直须严格依"判定定理"找条件、"性质定理"出结论，方向不可颠倒。
· 求空间角先"作角"后"计算"，作角须说明依据，计算常化归到三角形求解。
· 二面角的平面角常用定义法、三垂线法或垂面法作出，须注意角的范围与锐钝。

贰

空间向量与立体几何

单元二

  • 空间向量的概念、表示与相等向量、相反向量
  • 空间向量的加减运算（三角形、平行四边形法则）与数乘运算
  • 空间向量数量积 a·b=|a||b|cosθ 及其运算律
  • 共线向量定理：a=λb（b≠0）
  • 共面向量定理：p=xa+yb
  • 空间向量基本定理：任意向量可由不共面的基底唯一表示
  • 空间向量的正交分解与坐标表示、坐标运算
  • 用坐标计算距离、夹角与垂直关系
  • 平面法向量的求法与应用
  • 向量法求线线角、线面角
  • 向量法求二面角与点面距、线面距

核心公式

数量积：a·b = |a||b|cosθ
坐标数量积：a·b = x₁x₂+y₁y₂+z₁z₂
向量模：|a| = √(x²+y²+z²)
夹角：cos⟨a,b⟩ = (a·b)/(|a||b|)
线面角：sinθ = |cos⟨a,n⟩|
二面角：|cosθ| = |cos⟨n₁,n₂⟩|
点面距：d = |AP·n|/|n|

方法要点与易错警示

· 建系须"正交、尽量多落坐标"，便于简化运算。
· 求法向量后须验证方向，二面角是锐角还是钝角须结合图形判断符号。
· 向量法求线面角注意"线面角与线法向量夹角互余"，应取 sin 而非 cos。

叁

平面解析几何（直线与圆）

单元三

  • 直线的倾斜角 α（0≤α<π）与斜率 k=tanα
  • 直线方程的点斜式 y-y₀=k(x-x₀)
  • 直线方程的斜截式 y=kx+b
  • 直线方程的两点式与截距式 x/a+y/b=1
  • 直线方程的一般式 Ax+By+C=0
  • 两直线平行与垂直的判定（垂直 A₁A₂+B₁B₂=0）
  • 两直线的夹角与到角公式
  • 点到直线的距离公式
  • 圆的标准方程 (x-a)²+(y-b)²=r²
  • 圆的一般方程 x²+y²+Dx+Ey+F=0（D²+E²-4F>0）
  • 点与圆、直线与圆的位置关系判定
  • 圆与圆的位置关系及圆的切线方程

核心公式

点斜式：y - y₀ = k(x - x₀)
一般式：Ax + By + C = 0
点线距：d = |Ax₀+By₀+C| / √(A²+B²)
平行线距：d = |C₁-C₂| / √(A²+B²)
圆方程：(x-a)² + (y-b)² = r²
圆心到直线距：d = |Aa+Bb+C| / √(A²+B²)
切线长：√(d²-r²)

方法要点与易错警示

· 斜率不存在时（α=π/2）点斜式、斜截式失效，须单独讨论铅直线。
· 处理圆的问题优先用几何法（圆心距与半径关系），代数法（联立判别式）作补充。
· 求切线方程区分"过圆上点"与"过圆外点"两类，圆外点通常有两条切线。

肆

圆锥曲线（椭圆）

单元四

  • 椭圆第一定义：|PF₁|+|PF₂|=2a（2a>2c）
  • 标准方程 x²/a²+y²/b²=1（焦点在x轴，a>b>0）
  • 标准方程 y²/a²+x²/b²=1（焦点在y轴）
  • 范围与对称性（关于x轴、y轴、原点对称）
  • 顶点、长轴2a、短轴2b，关系 a²=b²+c²
  • 离心率 e=c/a（0<e<1）
  • 准线方程 x=±a²/c
  • 焦半径公式 |PF|=a±ex
  • 焦点弦与通径长 2b²/a
  • 点与椭圆的位置关系（代入比较1）

核心公式

定义：|PF₁|+|PF₂| = 2a
标准方程：x²/a² + y²/b² = 1（a>b>0，c²=a²-b²）
离心率：e = c/a（0<e<1）
准线：x = ±a²/c
焦半径：|PF| = a ± ex
通径：2b²/a

方法要点与易错警示

· 焦点位置决定方程形式，先由焦点坐标定 a² 所在轴，避免 a²、b² 写反。
· 求椭圆方程常用待定系数法，定义法（到两焦点距离和为定值）亦是重要路径。
· 弦长、面积问题常联立方程用韦达定理整体处理，减少坐标直接求解。

伍

圆锥曲线（双曲线）

单元五

  • 双曲线第一定义：||PF₁|-|PF₂||=2a（2a<2c）
  • 标准方程 x²/a²-y²/b²=1（焦点在x轴）
  • 渐近线方程 y=±(b/a)x
  • 等轴双曲线 a=b，渐近线 y=±x，e=√2
  • 共轭双曲线 x²/a²-y²/b²=1 与 y²/b²-x²/a²=1
  • 范围、对称性与顶点（两实顶）
  • 离心率 e=c/a（e>1）
  • 准线方程 x=±a²/c
  • 焦半径公式与焦点弦性质
  • 双曲线第二定义（到焦点与到准线距离之比为 e）

核心公式

定义：||PF₁|-|PF₂|| = 2a
标准方程：x²/a² - y²/b² = 1（c²=a²+b²）
渐近线：y = ±(b/a)x
离心率：e = c/a（e>1）
准线：x = ±a²/c
通径：2b²/a

方法要点与易错警示

· 双曲线 c²=a²+b²，与椭圆 c²=a²-b² 相反，最易记混出错。
· 求双曲线方程先定焦点轴与渐近线，再用待定系数法。
· 区分"过点"与"渐近线已知"两类条件，渐近线仅决定 b/a 的比值。

陆

圆锥曲线（抛物线）

单元六

  • 抛物线定义：动点到焦点距离等于到准线距离
  • 标准方程 y²=2px（焦点(p/2,0)，准线 x=-p/2，p>0）
  • 标准方程 y²=-2px（焦点(-p/2,0)，准线 x=p/2）
  • 标准方程 x²=2py 与 x²=-2py（焦点在y轴）
  • 范围、对称性（轴对称）、顶点（原点）
  • 离心率 e=1
  • 焦半径公式 |PF|=x+p/2（对 y²=2px）
  • 焦点弦性质 x₁x₂=p²/4，y₁y₂=-p²
  • 通径长 2p 与焦点弦弦长公式

核心公式

定义：|PF| = d（到准线距离）
标准方程：y² = 2px（焦点(p/2,0)，准线 x=-p/2）
焦半径：|PF| = x + p/2
焦点弦：x₁x₂ = p²/4，y₁y₂ = -p²
通径：2p

方法要点与易错警示

· 四种标准方程由"一次项"定开口方向，p 的几何意义是焦点到准线距离之半。
· 抛物线问题优先用定义（到焦点=到准线）转化距离，常比联立计算更简便。
· 焦点弦的 x₁x₂、y₁y₂ 是常用定值结论，须对应 y²=2px 这一标准形式。

柒

直线与圆锥曲线综合

单元七

  • 直线与圆锥曲线位置关系：相交、相切、相离
  • 联立方程组与消元（消 x 或消 y）
  • 判别式 Δ 判断交点个数（注意二次项系数是否为0）
  • 弦长公式 √(1+k²)|x₁-x₂| 与 √(1+1/k²)|y₁-y₂|
  • 中点弦问题与点差法
  • 韦达定理 x₁+x₂、x₁x₂ 的整体代入
  • 面积问题：三角形面积、四边形面积
  • 定点问题：设参数后令恒等式成立
  • 定值问题：计算结果与参数无关
  • 轨迹方程的直接法与定义法
  • 轨迹方程的相关点法（代入法）与参数法

核心公式

弦长：L = √(1+k²)|x₁-x₂|
弦长：L = √(1+1/k²)|y₁-y₂|
点差法（椭圆）：k = -b²x₀/(a²y₀)
面积：S = (1/2)|x₁-x₂|·d（d 为点到直线距离）
韦达定理：x₁+x₂ = -B/A，x₁x₂ = C/A

方法要点与易错警示

· 联立后须先检查二次项系数，斜率使二次项为0时只有一个交点，不能套用韦达定理。
· "设而不求"是核心思想，弦长、面积、中点问题统一用韦达定理整体处理。
· 定点定值问题常用"特殊值探路+一般证明"两步法，先猜后证。
