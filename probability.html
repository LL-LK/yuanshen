概率与统计

概率是命运的骰子，统计是规律的凝视。如稻妻雷电的瞬息万变，随机世界中亦蕴含确定的法则。本章覆盖计数原理、概率、随机变量、统计四大知识单元。

壹

计数原理

单元一

  • 分类加法计数原理：完成一件事有 n 类方案，第 i 类有 mᵢ 种方法，则总方法数 N=m₁+m₂+…+mₙ。
  • 分步乘法计数原理：完成一件事分 n 步，第 i 步有 mᵢ 种方法，则总方法数 N=m₁×m₂×…×mₙ。
  • 排列：从 n 个不同元素中任取 m(m≤n) 个按一定顺序排成一列，排列数 A(n,m)=n!/(n-m)!。
  • 全排列与阶乘：A(n,n)=n!，规定 0!=1，且 A(n,m)=n(n-1)…(n-m+1)。
  • 组合：从 n 个不同元素中任取 m(m≤n) 个并成一组，组合数 C(n,m)=n!/[m!(n-m)!]。
  • 组合数性质一（对称性）：C(n,m)=C(n,n-m)，C(n,0)=C(n,n)=1。
  • 组合数性质二（递推）：C(n,m)=C(n-1,m-1)+C(n-1,m)（帕斯卡恒等式）。
  • 二项式定理：(a+b)ⁿ=Σ(k=0→n)C(n,k)aⁿ⁻ᵏbᵏ，展开式共 n+1 项。
  • 通项公式：T(k+1)=C(n,k)aⁿ⁻ᵏbᵏ（k 从 0 起算，对应第 k+1 项）。
  • 二项式系数性质：对称性 C(n,k)=C(n,n-k)；增减性（中间项前增后减）；最大项居中。
  • 赋值法求系数和：令 a=b=1 得 ΣC(n,k)=2ⁿ；令 a=1、b=-1 得奇偶项系数差。

核心公式

A(n,m)=n!/(n-m)!　C(n,m)=n!/[m!(n-m)!]　C(n,m)=C(n-1,m-1)+C(n-1,m)　(a+b)ⁿ=ΣC(n,k)aⁿ⁻ᵏbᵏ　T(k+1)=C(n,k)aⁿ⁻ᵏbᵏ

方法要点与易错警示

排列"有序"、组合"无序"：含"排队、编号、排序"等有序信号用 A(n,m)，含"选取、分组、抽样"等无序信号用 C(n,m)。
通项 T(k+1) 中 k 从 0 起，求第 r 项取 k=r-1；区分"二项式系数 C(n,k)"与含 a、b 的"该项系数"。
赋值法令 a=b=1 得各项系数和 2ⁿ，注意"二项式系数和"与"各项系数和"在 a、b 带系数时并不相同。

随机事件的概率

单元二

  • 随机试验与样本空间：试验可重复、结果明确但不确定；样本空间 Ω 为所有基本事件（样本点）的集合。
  • 随机事件：Ω 的子集；基本事件只含一个样本点；必然事件 Ω 概率为 1，不可能事件 ∅ 概率为 0。
  • 频率与概率：频率 fₙ(A)=m/n 随试验波动，概率 P(A) 是频率的稳定值；大量重复试验中频率趋于概率。
  • 古典概型：基本事件有限且等可能，P(A)=A 包含的基本事件数 m / 总数 n。
  • 几何概型：基本事件无限且等可能，P(A)=构成 A 的区域测度 / 整个区域测度（长度、面积、体积）。
  • 概率基本性质：0≤P(A)≤1；若 A⊆B 则 P(A)≤P(B)；P(∅)=0，P(Ω)=1。
  • 互斥与对立事件：互斥 A∩B=∅ 时 P(A∪B)=P(A)+P(B)；对立事件 P(A)+P(Ā)=1。
  • 概率加法公式（一般）：P(A∪B)=P(A)+P(B)-P(A∩B)。
  • 条件概率：P(A|B)=P(AB)/P(B)（P(B)>0），样本空间已缩减为 B。
  • 事件的独立性：P(AB)=P(A)P(B)（等价于 P(A|B)=P(A)）；独立与互斥一般不同时成立。
  • 全概率公式与贝叶斯公式：P(B)=ΣP(Aᵢ)P(B|Aᵢ)；P(Aᵢ|B)=P(Aᵢ)P(B|Aᵢ)/ΣP(Aⱼ)P(B|Aⱼ)（后验概率）。

核心公式

P(A)=m/n　P(A∪B)=P(A)+P(B)-P(A∩B)　P(A|B)=P(AB)/P(B)　P(AB)=P(A)P(B)　P(B)=ΣP(Aᵢ)P(B|Aᵢ)

方法要点与易错警示

古典概型必须先确认"等可能"再计数；几何概型注意测度选择（线段长度、平面面积、立体体积）。
互斥（A∩B=∅）与独立（P(AB)=P(A)P(B)）是不同概念：互斥事件一般不独立，独立事件一般不互斥。
条件概率 P(A|B)≠P(AB)：前者样本空间已缩减为 B，后者仍在原 Ω 下；全概率公式要求 A₁,…,Aₙ 两两互斥且并为 Ω。

随机变量及其分布

单元三

  • 随机变量：把每个样本点对应到一个实数的函数；离散型取值可列举，连续型取值充满某区间。
  • 离散型随机变量的分布列：列出 X 的所有取值 xᵢ 与对应概率 pᵢ=P(X=xᵢ) 的表格。
  • 分布列性质：pᵢ≥0（i=1,2,…）且 Σpᵢ=1。
  • 数学期望：E(X)=Σxᵢpᵢ，刻画 X 取值的平均水平，是一个常数。
  • 方差与标准差：D(X)=Σ(xᵢ-E(X))²pᵢ=E(X²)-[E(X)]²，σ(X)=√D(X)，度量偏离程度。
  • 期望与方差的线性性质：E(aX+b)=aE(X)+b，D(aX+b)=a²D(X)。
  • 两点分布（0-1 分布）：X 只取 0、1，P(X=1)=p；E(X)=p，D(X)=p(1-p)。
  • 二项分布：n 次独立伯努利试验，X~B(n,p)，P(X=k)=C(n,k)pᵏ(1-p)ⁿ⁻ᵏ；E(X)=np，D(X)=np(1-p)。
  • 超几何分布：N 件含 M 件次品，无放回抽 n 件，P(X=k)=C(M,k)C(N-M,n-k)/C(N,n)。
  • 正态分布 N(μ,σ²)：密度曲线关于 x=μ 对称，E(X)=μ，D(X)=σ²；σ 越大数据越分散。
  • 3σ 原则：P(μ-σ<X<μ+σ)≈0.6827，P(μ-2σ<X<μ+2σ)≈0.9545，P(μ-3σ<X<μ+3σ)≈0.9973。
  • 连续型随机变量：密度函数 f(x)≥0 且 ∫f(x)dx=1，P(a<X<b)=∫ₐᵇf(x)dx。

核心公式

E(X)=Σxᵢpᵢ　D(X)=E(X²)-[E(X)]²　E(aX+b)=aE(X)+b, D(aX+b)=a²D(X)　X~B(n,p): E=np, D=np(1-p)　N(μ,σ²)

方法要点与易错警示

写完分布列务必验证 Σpᵢ=1 且 pᵢ≥0，否则不构成分布列。
二项分布（有放回/独立重复）与超几何分布（无放回抽样）勿混；总体很大时超几何分布可近似为二项分布。
D(aX+b)=a²D(X) 中系数平方、常数消失是高频易错点；正态分布 σ 是标准差、σ² 才是方差。

统计与统计分析

单元四

  • 简单随机抽样：逐个等可能抽取（抽签法、随机数法），适合总体量小、个体差异小的情形。
  • 系统抽样：编号后按固定间隔 k=N/n 抽取，起点随机，适合总体均匀、量大的情形。
  • 分层抽样：按差异分层，按比例在各层独立抽取，层内差异小、层间差异大时最有效。
  • 频率分布直方图：横轴分组、纵轴为"频率/组距"，小矩形面积=该组频率，所有矩形面积和=1。
  • 众数、中位数、平均数：众数为出现最多的值；中位数为排序居中值；平均数 x̄=Σxᵢ/n。
  • 方差与标准差：s²=Σ(xᵢ-x̄)²/n，标准差 s=√s²，度量数据离散程度，单位与原数据一致。
  • 样本估计总体：用样本均值、方差估计总体均值、方差；样本量越大估计越精确。
  • 相关关系与散点图：散点图判断正/负相关；相关系数 r 刻画线性相关强弱，|r|≤1。
  • 相关系数：r=Σ(xᵢ-x̄)(yᵢ-ȳ)/√[Σ(xᵢ-x̄)²·Σ(yᵢ-ȳ)²]，r>0 正相关、r<0 负相关、|r|→1 强相关。
  • 最小二乘法与回归方程：ŷ=bx+a 使残差平方和最小；b=Σ(xᵢ-x̄)(yᵢ-ȳ)/Σ(xᵢ-x̄)²，a=ȳ-bx̄。
  • 回归分析与残差：残差 eᵢ=yᵢ-ŷᵢ；残差图用于检验拟合优劣，回归预测仅适用于样本范围内。
  • 独立性检验：2×2 列联表，χ²=n(ad-bc)²/[(a+b)(c+d)(a+c)(b+d)]，与临界值比较判断相关性。

核心公式

x̄=Σxᵢ/n　s²=Σ(xᵢ-x̄)²/n　ŷ=bx+a, b=Σ(xi-x̄)(yi-ȳ)/Σ(xi-x̄)²　r=Σ(xi-x̄)(yi-ȳ)/√[Σ(xi-x̄)²Σ(yi-ȳ)²]　χ²=n(ad-bc)²/[(a+b)(c+d)(a+c)(b+d)]

方法要点与易错警示

频率分布直方图纵轴是"频率/组距"而非频率；估算中位数找面积累计到 0.5 处，众数取最高矩形中点。
相关系数 r 只刻画线性相关，r≈0 不等于无关系（可能非线性）；回归预测仅在样本范围内有效，外推需谨慎。
独立性检验 χ² 越大越有把握认为相关，结论表述为"在犯错误不超过 α 的前提下"，而非"一定相关"。
